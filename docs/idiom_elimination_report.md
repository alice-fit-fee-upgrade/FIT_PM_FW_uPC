# Repeated ASM idiom elimination pass

**FLASH EXACT MATCH: YES. Differing bytes: 0.** Standard AVR GCC 7.3.0 and the
existing per-file profiles were retained. No new pragmas, optimization flags,
compiler patches, golden changes or exact_asm changes were introduced.

## Findings and limits

* Byte comparison works naturally where GCC sees the actual local branch target
  and the original bound register. No dummy volatile or dead code is needed.
  The zero-byte register input captures express the existing private ABI.
* LD/LD includes 14 configuration word loads, 3 DMA field windows, 2 shared queue
  post-increment windows and 1 pre-decrement window. Those are not interchangeable
  uint16_t loads. Normal word access through the fixed global Y often generates
  `LD Y; LDD Y+1; ADIW Y,2`, rather than two LD Y+ instructions: it adds bytes and
  changes flags. Other profiles require different registers or stack saves; some
  fixed-pointer variants cannot allocate POINTER_REGS at all.
* ST/ST includes 8 configuration word windows, 5 DMA field windows, 6 overlapping
  repeated-fill windows and 1 cross-value stream window. Adjacent bytes may belong
  to two different values; the pair at 0x1e0e stores R25 then R20. Word, byte,
  struct, fixed-global-pointer and three-byte fill candidates were rejected.
* Signed comparisons must keep signedness and the preloaded high-byte operand.
  A dead-value C probe uses destructive SBCI. Keeping the value live avoids that
  particular choice but introduces a new constant register and still differs.
  The natural C shared-error wrapper expands section sizes/branches; it was
  rolled back. `<`, `<=`, `>` variants are experiments with their own semantics,
  not accepted replacements for `>=`.
* Many remaining byte comparisons enter shared assembler error tails outside
  the C function's CFG. A readable C condition followed by a shared-error jump
  changed section sizes and branch reach. Both that family experiment and the
  individually rejected local comparisons remain reproducible in the lab.
* All 22 carry-status calls now use a named in-place primitive. C=1 means parser
  failure, password rejection **or transfer completion**, depending on callee.
  See [legacy_abi.md](legacy_abi.md). No shared machine-code body was introduced.

The natural memory candidates failed, so there is no exact load/store solution
to propagate to their unmodified class members. All occurrences are nevertheless
inventoried and classified. These results do not prove that later local compiler
control cannot improve them; that separate pragma/attribute pass was not run.

Largest remaining families in this inventory: CPI/BRNE **35 / 140 B**,
CPI/CPC/BRGE **16 / 96 B**, RCALL/BRCS **22 / 88 B**, LD/LD **20 / 78 B**,
ST/ST **20 / 66 B**.
