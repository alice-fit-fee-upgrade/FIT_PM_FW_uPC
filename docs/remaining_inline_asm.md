Priority constraints for the next recovery pass:

- Short RCALLs: this target still emits wide CALL for GNU calls even with
  -mshort-calls. Preserve short-call helpers; no global relaxation is appropriate.
- Stack/frame instructions: private ISR/save/shared-entry frames differ from GNU
  function/interrupt frames. Converting surrounding bodies to C does not remove
  these exact contracts.
- Comparisons/conditional branches: retain original signedness, live flags and
  shared tails. Four further clean parser/profile attempts (318–321) failed
  exact layout or register allocation; original ASM and C comment alternatives
  were preserved.
- Zeroing and carry: original EOR/CLR, ADC/SBC/ROR and MUL/dirty-R1 state are not
  interchangeable with compiler zero constants or ordinary GNU zero-register ABI.
- Pointer loads/stores: many exact postincrement/predecrement sequences need
  extra registers or frames in clean C. Small profile adjustments were tried;
  differing code was restored rather than accepted as behavioral equivalence.

These constraints justify the retained helpers; they are not a proof that every
future isolated region/profile conversion is impossible. The authoritative gate
remains complete canonical FLASH equality in root `make exact-check`.
