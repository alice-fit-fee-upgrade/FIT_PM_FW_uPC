Windows overlap; neither rows nor families can be summed. Registers, side effects,

Recommended next targeted investigation: LD pairs with incrementing X/Y/Z,
starting from a function with a conventional bound pointer rather than a global
register object. Test a clean byte/word read with narrowly adjusted allocation
options, then reuse only a demonstrated zero-difference pattern in independent
functions. This offers a repeated native-C opportunity without changing the
private return ABI. Previous straightforward pointer trials were rejected;
this ranking does not claim a working solution yet.

CPI/BRNE is the largest comparison family, often delimiter validation around
console parsing. A local destination may compile directly. An external shared
error label requires an exact bridge or another mechanism preserving the
original short conditional branch; a new local trampoline changes bytes.
A typed delimiter guard can improve readability even when the bridge remains ASM.

CPI/CPC/BRGE is a repeated signed word comparison. GCC may select equivalent
but different comparison encodings, and external shared error destinations
remain a constraint. It merits one focused prototype rather than many unrelated
rewrites. RCALL/BRCS additionally returns status through carry: ordinary C
materialization can add instructions, so a small exact bridge is appropriate.

PUSH/POP chains also repeat heavily, but entry saves were already recovered in
steps 590–622. Remaining chains frequently have mandated order, save SREG or
R1, or belong to shared return tails; ordinary GNU prologues cannot be assumed
to reproduce them. The statistical ranking alone does not justify a rewrite.

No firmware source was changed by this audit. Native C remains 6880 bytes;
canonical FLASH remains the checkpoint-702 zero-difference image.
